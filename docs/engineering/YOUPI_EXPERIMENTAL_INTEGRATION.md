# YOUPI-PG Experimental Integration Boundary & Audit Report

**Status:** Isolated, Opt-In Experimental Port  
**Default State:** `DISABLED` (`YOUPI_ENABLED=false`)  
**License Baseline:** Do Not Vendor / Clean API Boundary Only  

---

## 1. Context & Architecture Decision

YOUPI-PG is a third-party project providing notification/SMS observer-based tracking of personal UPI VPA transactions. Inspection of its package metadata revealed `private: true` and `license: Commercial`, with absence of an explicit permissive root open-source license.

### Non-Vendoring Policy
In accordance with enterprise IP and copyright safety directives:
1. **Zero External Code Ingestion:** No source files, dependencies, or modules from YOUPI-PG are vendored, copied, or bundled into Gadispot.
2. **Interface Isolation:** An abstract client port (`YoupiPaymentAdapter`) is implemented behind `PaymentGatewayPort`.
3. **No Automated Settlement:** Under NPCI and RBI regulatory guidelines, push notifications and SMS snippets do not constitute bank settlement. Therefore, any observation event generated by YOUPI-PG is strictly treated as telemetry (`OBSERVED_SUCCESS`) and **cannot** confirm a parking reservation without explicit secondary reconciliation.

---

## 2. Configuration & Activation Guards

YOUPI-PG is disabled by default in all environments. To evaluate in an isolated sandbox, the following explicit environment variables must be declared:

```ini
# YOUPI-PG Experimental Gateway (Disabled by default)
YOUPI_ENABLED=true
YOUPI_BASE_URL=https://youpi.sandbox.local/api
YOUPI_API_KEY=test_youpi_api_key_sandbox
YOUPI_WEBHOOK_SECRET=test_youpi_hmac_webhook_secret
```

If `YOUPI_ENABLED=false` (or undefined), any attempt to initialize or invoke the adapter fails immediately with `ValidationException: YoupiPaymentAdapter is experimental and currently DISABLED`.

---

## 3. Webhook Signature & Security Controls

YOUPI-PG webhooks are cryptographically authenticated via HMAC-SHA256:

```python
computed = hmac.new(webhook_secret.encode("utf-8"), payload_bytes, hashlib.sha256).hexdigest()
is_valid = hmac.compare_digest(header_signature, computed)
```

- **Connection Timeout:** Strict 3.0s connect / 5.0s read timeouts.
- **Fail Closed:** If forged or missing HMAC header is supplied, the webhook responds with HTTP 401 Unauthorized.
